# Data

The raw data is the public [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (about 100k orders from 2016 to 2018, 9 CSV files). It is not stored in this repository.

To download it into this folder:

```bash
pip install kagglehub
python scripts/download_data.py
```

Or download the zip from the Kaggle page and extract the CSV files here.
